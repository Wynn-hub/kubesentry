# Code of Conduct

## Our Commitment

We are committed to providing a welcoming and supportive environment for all contributors and users, regardless of background, experience level, or identity.

## Expected Behavior

Contributors are expected to:

- **Be respectful**: Treat all community members with respect in all interactions
- **Be inclusive**: Welcome and support people of all backgrounds
- **Be constructive**: Provide helpful feedback and engage in good-faith discussions
- **Be collaborative**: Work together to resolve disagreements and improve the project
- **Be professional**: Keep discussions focused on the project and technical matters

## Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment, discrimination, or intimidation based on any characteristic
- Offensive or disrespectful comments, slurs, or personal attacks
- Unwelcome sexual attention or advances
- Deliberate intimidation or threats
- Publishing others' private information without consent
- Sustained disruption of discussions or community activities

## Reporting Violations

If you experience or witness a violation of this code of conduct:

1. **Contact maintainers**: Email wying8408@gmail.com with details
2. **Private discussions**: Reports will be handled confidentially
3. **No retaliation**: The project does not tolerate retaliation against reporters

## Enforcement

Violations may result in:

- A private warning or discussion
- Temporary suspension from the community
- Permanent removal from the project

Enforcement decisions are made by project maintainers and are final.

## Scope

This code of conduct applies to all community interactions:

- GitHub issues and pull requests
- Code review discussions
- Project documentation
- Community forums and chat channels
- In-person events and conferences

## Attribution

This Code of Conduct is adapted from community standards and best practices in open source projects.
