# KubeSentry Member-Cluster Chart

Installs Webhook, Operator, Events Server, CRDs, built-in policies, and TLS setup in a member cluster. A reachable KubeSentry Gateway and one-time registration data are required; standalone installation is not supported.

Use the complete command generated by **Console → Cluster Management**. Its required values include:

```yaml
gateway:
  address: "gateway.example:30443"
  tlsServerName: "gateway.example"
  clusterName: "member-name"
  registrationToken: "one-time-token"
```

| Traffic | Default port | Purpose |
|---|---:|---|
| Operator → Gateway | TLS/TCP 30443 or configured address | Registration and sync |
| kube-apiserver → Webhook Service | TCP 443 → 8443 | AdmissionReview |
| Webhook → Events Server | TCP 8082 | Events and observations |

Key values are defined and documented inline in [`values.yaml`](values.yaml). Upgrade with `helm upgrade`; initiate uninstall from Console so managed resources are cleaned before removing the release. See the repository [installation guide](../../docs/en-US/installation.md) and [network guide](../../docs/en-US/network.md).
