# 文档维护指南

## 必须同步的变更

| 代码变更 | 必须检查并更新 |
|---|---|
| 用户功能、权限、页面或错误处理 | 帮助中心、中英文详细文档 |
| 组件、数据流或安全边界 | 两张 `.drawio`、对应 SVG、README 架构章节 |
| Helm values、端口、协议或网络方向 | 两份 README、network 文档、帮助中心、Chart README |
| 安装、升级、卸载或迁移 | installation 文档和 README 快速开始 |
| API/CRD 契约 | API 文档入口、示例和相关使用说明 |
| 内置规则或策略行为 | 规则说明及 Polaris 参考边界 |

中文是主要内容源，但合并前必须保证英文含义、链接、参数和图示同步。图必须提交可编辑 `.drawio` 源文件与 README 使用的 SVG。评审时核对实际 Chart/代码而不是复制旧文档；无法同步的内容必须在提交说明中标明原因和风险。

## 完成检查

检查内部链接、前端中英文 key、Help Center 两种语言、Helm lint、前端测试和构建。文档变更不得包含令牌、密码、真实地址或内部凭据。
